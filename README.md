# DIFS

Code accompanying the manuscript

"DIFS: Discriminative Feature Selection for Cell Clustering Based on Single-Cell RNA Sequencing Data"

## Requirements

- R >= 4.1
- Seurat
- SingleCellExperiment
- diptest
- mclust

## Files

R/

- Functions_mixture_auto.R
  Main functions.

- Method_comparison.R
  Runs benchmark methods.

- scenario_generator.R
  Generates simulated datasets.

- results_summary.R
  Summarizes results.

scripts/

- run_method_comparison_mixture_auto.sh
- run_scenario_generator.sh
